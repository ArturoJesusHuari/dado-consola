# Dado en la terminal

Un dado animado en 3D dibujado directamente en la terminal con Python. Cada tirada muestra una de las seis caras, con los puntos distribuidos como en un dado convencional.

## Requisitos

- Python 3.8 o superior.
- Una terminal compatible con secuencias ANSI y caracteres Unicode.
- No requiere dependencias externas.

## Cómo ejecutar

Clona o descarga este repositorio y, desde la carpeta del proyecto, ejecuta:

```bash
python main.py
```

En algunos sistemas puede que debas usar `python3`:

```bash
python3 main.py
```

## Controles

- **Enter**: lanzar el dado.
- **q**: salir.

El resultado se selecciona usando el generador aleatorio seguro incluido en la biblioteca estándar de Python.
